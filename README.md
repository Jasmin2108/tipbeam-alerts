## Add to OBS
1. Sources → + → **Browser**, width 1920, height 1080.
2. Paste a skin URL above (add `?lang=fi` for Finnish).
3. Works on Kick, YouTube, Twitch, TikTok Live, etc.

## Params
`?name=&amount=&message=&lang=en|fi|sv` → tip popup. No params = demo every 8s.
Goal jar: `?title=&current=&target=&lang=`
